Build order

1

MUST FIX Walmart prep as a step on the order

What’s wrong today On a Walmart order, staging shows a red warning and sends you to Card Vault. The step list jumps from Paid to Allocated — no preparation step in between.
What “done” looks like When an order has Walmart cards, a Card Preparation step sits between Paid and Allocated. From that step: download the work file, import activated results — without making Card Vault the main path. The app still does not open Fiserv or activate cards for Progressive.
Design source Kaitlin’s Walmart order Screens (step order + layout). Copy follows prepare → they activate → import (even if some frames still sound more “generate in the app”).
How we’ll know it works Walk a Walmart test order: Paid → prepare work file → Progressive activates outside the app → import results → ready to allocate. Order context never disappears into a side page.
2

MUST FIX Status labels that say the real state

What’s wrong today Paid is already green — this is not a “make paid green” job. The problem is the words: paid often shows as Completed, and different fulfillment states all say generic In Progress. Hard to scan at a glance.
What “done” looks like Clear labels that match Screens — e.g. Paid, Needs Generation, Ready to Allocate, Allocated, Export created, Closed — same language on dashboard, Orders list, and order header. Keep the current color family; fix the words.
How we’ll know it works Same order looks consistent in three places (home, Orders list, order page) without decoding jargon.
3

CHECK Team walkthrough on staging

After 1 and 2, walk the Walmart test order end-to-end and spot-check status words on home + Orders list. Only then spend time on the smaller items below.

4

SOON AFTER Order page: keep secondary panels collapsed

“Allocated Cards” and “Order Activity” currently open automatically when an export exists — pushes focus away from the step list. Default them closed; counts still show in the headers.

5

SOON AFTER Small wording cleanup

  • “Search requests…” → “Search orders…”
  • Card Vault button “Generate Cards” → preparation language (e.g. prepare / import)

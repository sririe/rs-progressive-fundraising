# Progressive Discovery Task Breakdown

## Recommended Asana Sections

1. Client Coordination
2. Discovery Prep
3. Prework And Analysis
4. On-Site Session
5. Post-Session Synthesis

## Suggested Tasks

| Section | Task | Suggested Owner | Notes |
| --- | --- | --- | --- |
| Client Coordination | Finalize and send Progressive follow-up email | Danny / Spencer | Update the existing draft, include the digital-first framing, and send date options |
| Client Coordination | Confirm on-site date and attendee list | Danny | Lock the session date and confirm Doug, Lloyd, Mario, and any optional attendees |
| Client Coordination | Send client prework request | Danny | Ask for vendor list, sample inputs and outputs, and any constraints around recording or screenshots |
| Discovery Prep | Draft printable discovery session brief | Bronte | Use the client-facing brief as the base artifact Danny can print and bring |
| Discovery Prep | Draft live walkthrough checklist | Danny | Build the note-taking/checklist sheet to keep the walkthrough on track without making it feel rigid |
| Discovery Prep | Confirm recording approach and permission | Danny | Decide on Google Meet versus Loom and make sure Progressive is comfortable with the capture method |
| Discovery Prep | Draft first-pass SOW update | Spencer | Keep discovery focused on digital fulfillment while acknowledging adjacent inputs |
| Discovery Prep | Confirm Red Stamp roles for the session | Spencer | Clarify who is on site, who joins remotely, and who owns follow-up outputs |
| Prework And Analysis | Build current digital vendor list from the website | Danny | Create the starting worksheet Progressive can confirm or correct |
| Prework And Analysis | Clean and summarize order export data | Tim | Validate digital versus physical counts, order sizes, and any useful directional data |
| Prework And Analysis | Pair vendor list with known sourcing questions | Danny | Add fields for upstream source, format, activation, output type, and exceptions by vendor |
| On-Site Session | Run on-site discovery walkthrough | Danny | Lead the session, capture workflow details, and gather example artifacts where possible |
| On-Site Session | Capture technical questions and follow-ups in real time | Spencer / technical support | Track unknowns, edge cases, and items that require later validation |
| Post-Session Synthesis | Draft vendor runbooks from session notes | Danny | Convert the walkthrough into operator-readable documentation |
| Post-Session Synthesis | Produce security and handoff assessment | Spencer / Tim | Summarize sensitive data flow, operator dependency, and priority risks |
| Post-Session Synthesis | Produce recommended next-step memo | Spencer | Translate discovery into a recommendation on what to build next and what to defer |

## Import Notes

The CSV companion file at `projects/gift-cards/docs/plans/inbox/2026-03-19-progressive-asana-import.csv` is formatted to be a reasonable starting point for Asana CSV import.

Before import, it would be worth checking:

- whether the target Asana project already has matching sections
- whether assignees should be matched by name or replaced with email addresses
- whether you want to keep the tasks flat or convert some prep items into subtasks after import

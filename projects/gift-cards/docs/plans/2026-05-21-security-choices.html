Deeper context - security choices

Where card data lives

Progressive is handling cash-equivalent data: card numbers, PINs, claim codes, URLs, and generated PDFs. The proposal needs an explicit choice about where that data lives and who can support the system.

Current model

Trusted local workflow

Card data lives in local folders, Google Drive structures, scripts, and spreadsheets handled by trusted operators.

Design question

Support vs exposure

The more Redstamp can support remotely, the more deliberate the security choices need to be.

Default path

Secure Web Vault

The current recommendation is a web vault because it supports the roadmap without rebuilding the foundation later.

Options to compare

Option A

Local workstation tool

Card data stays on Progressive machines. This is closest to the current model, but remote support is limited.

  • Fastest first build
  • Least internet exposure
  • Harder for Redstamp to support
  • Not a strong foundation for portal or recipient delivery
Option B

Secure Web Vault

Card data lives in a secured web application with access controls, encrypted storage, order records, and cleanup rules.

  • Recommended default
  • Supports remote troubleshooting
  • Best foundation for future portal work
  • Requires disciplined security design
Option C

Hybrid processing

The web app manages workflow, while raw card processing happens in a separate controlled environment.

  • Strongest separation
  • Most expensive to build and support
  • Better for enterprise security review
  • Likely too heavy for current volume

What the choice controls

Question What needs to be decided Why it matters
Who can see card data? Define roles for operators, managers, Redstamp support, and future staff. Card numbers and PINs are cash-equivalent. Access should not be implied by habit.
How long do files stay? Decide when generated PDFs, ZIPs, spreadsheets, and delivery files are removed or archived. Keeping everything forever increases exposure; deleting too soon can hurt support.
What order activity gets recorded? Track who processed the order, what was created, what was sent, and what failed. This gives Progressive and Redstamp a support record when customers ask questions later.
How does Redstamp support it? Decide whether support happens through a web admin view, logs, screen shares, or site visits. The answer affects support cost, response time, and how dependent Progressive remains on Lloyd.

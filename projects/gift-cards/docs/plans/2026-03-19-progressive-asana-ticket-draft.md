# Progressive Asana Ticket Draft

These proposed tickets are written to match the current project board style as closely as possible:

- title prefixes such as `[Discovery]`
- flat tasks instead of nested subtasks
- structured note bodies with `Task Overview`, `Action Items`, and `Harvest Time Tracking`
- all new work placed in `Incoming` for team triage
